# Final Interview Prep

This folder collects interview-relevant questions discovered throughout the course. By the time you finish the curriculum, this should cover the most commonly asked REST API and backend interview topics.

Questions are added as they come up naturally during lessons and quizzes. The final quiz will be compiled from these once all lessons are complete.

## Topics to Cover
- [ ] Path parameters vs query parameters
- [ ] HTTP methods (GET, POST, PUT, PATCH, DELETE)
- [ ] Status codes (200, 201, 204, 400, 401, 403, 404, 422, 500)
- [ ] REST API design principles
- [ ] Request/response cycle
- [ ] Authentication (JWT, OAuth2, API keys)
- [ ] Error handling patterns
- [ ] Database design basics (ORM, migrations, CRUD)
- [ ] Async vs sync
- [ ] Security (OWASP top 10)
- [ ] Environment configuration
- [ ] Project structure and code organization
